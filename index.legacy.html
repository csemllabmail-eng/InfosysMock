1. Number Series

Number-series questions usually test whether you can identify a simple mathematical relationship quickly.

Order of checking

  1. First differences.
  2. Second differences.
  3. Multiplication or division.
  4. Alternating operations.
  5. Squares, cubes, primes or powers.
  6. Two interleaved sequences.
Example: 3, 7, 11, 15 → differences are +4, so next = 19.
Shortcut: If differences are irregular, separate odd-position and even-position terms and test each sequence.
Trap: Do not choose a complicated pattern when a simpler rule explains every term.

2. Alphabet and Coding-Decoding

A=1, B=2, C=3 ... Z=26
Reverse position = 27 − normal position

Common patterns

  • Fixed forward shift: +1, +2, etc.
  • Fixed backward shift.
  • Increasing shifts: +1, +2, +3...
  • Alternating shifts.
  • Alphabet reversal.
  • Position-based numerical coding.
If C → F, shift = +3. Apply the same shift only if the examples support it.
Trap: A word may use a different rule for odd and even positions.

3. Analogy

Find the exact relationship between the first pair and apply the same relationship to the second pair.

Common relationships

  • Object → function
  • Worker → workplace
  • Part → whole
  • Cause → effect
  • Degree or intensity
  • Number → mathematical property
Method: Say the relationship as a sentence before looking at the options.

4. Classification / Odd One Out

Find the property shared by three or more options. The remaining option is the odd one.

  1. Check category.
  2. Check numerical property.
  3. Check spelling/letter pattern.
  4. Check function or relationship.
Avoid selecting an option merely because it looks different; the intended distinction is usually systematic.

5. Blood Relations

Convert the sentence into a family tree. Solve from the reference person outward.

Useful translations

  • Father's/mother's brother = uncle.
  • Father's/mother's sister = aunt.
  • Uncle/aunt's child = cousin.
  • Sibling's child = nephew/niece.
  • Parent's parent = grandfather/grandmother.
Draw generations on separate levels: grandparents → parents → children.
Do not assume gender from a name unless the question explicitly establishes it.

6. Direction Sense

North = up | South = down | East = right | West = left

Method

  1. Draw the starting point.
  2. Mark each movement.
  3. Combine horizontal movement separately from vertical movement.
  4. Determine final direction.
  5. Use Pythagoras only when straight-line distance is required.
If horizontal displacement = 3 and vertical = 4, shortest distance = √(3²+4²) = 5.
Distance travelled is not the same as shortest distance from start to finish.

7. Syllogism

Use only the statements. Do not add real-world knowledge.

All A are B → A is inside B
No A is B → A and B do not overlap
Some A are B → at least one overlap exists

Validity test

  1. Translate statements into sets.
  2. Test the conclusion.
  3. Ask: can the conclusion be false while all statements remain true?
  4. If yes, it does not necessarily follow.
Important: “Some” proves existence, but does not prove that every member has the property.

8. Statement and Assumption

An assumption is an unstated idea that must be accepted for the statement or argument to make sense.

Test

Ask whether the statement depends on the proposed assumption. If removing it destroys the reasoning, it is likely an assumption.

Do not confuse an assumption with a conclusion. The assumption is normally required but not directly stated.

9. Logical Sequence

For process/order questions, identify what must happen first and what depends on an earlier step.

  1. Find the starting event.
  2. Find prerequisite relationships.
  3. Connect dependent steps.
  4. Check the final outcome.
Words such as first, before, after, finally and then are strong ordering clues.

10. Data Sufficiency

The question is not necessarily asking you to calculate the exact answer. It asks whether the supplied information is sufficient.

  1. Use statement I alone.
  2. Use statement II alone.
  3. Use both together if needed.
  4. Do not use outside information.

1. Percentages

Percentage = (Part / Whole) × 100
Percentage change = (Change / Original) × 100

Example: 20% of 250 = 250/5 = 50.
A 20% increase followed by a 20% decrease does not return to the original value.

2. Profit, Loss and Discount

Profit = SP − CP
Loss = CP − SP
Profit% = Profit/CP × 100
Loss% = Loss/CP × 100
Discount = MP − SP

Fast approach

If CP = 100 and profit = 15%, SP = 115. If MP = 100 and discount = 20%, SP = 80.

Profit/loss percentage normally uses CP; discount percentage normally uses Marked Price.

3. Ratio and Proportion

a:b = c:d means a/b = c/d and ad = bc
  1. Simplify the ratio.
  2. Keep units identical.
  3. For direct proportion, both quantities increase/decrease together.
  4. For inverse proportion, one increases as the other decreases.
If ratio is 2:3 and total is 25, one part = 25/5 = 5, so values = 10 and 15.

4. Average

Average = Total / Number
Total = Average × Number

For replacement questions:

New total = Old total − old value + new value
For consecutive numbers, the average is the middle value when the count is odd.

5. Time, Speed and Distance

Distance = Speed × Time
Speed = Distance / Time
Time = Distance / Speed
1 m/s = 18/5 km/h
1 km/h = 5/18 m/s

Relative speed

  • Opposite directions → add speeds.
  • Same direction → subtract speeds.
Average speed is total distance / total time, not the simple average of two speeds unless the time/distance conditions justify it.

6. Simple Interest

SI = (P × R × T) / 100
Amount = P + SI

Use time in years unless another unit is specified. Convert months to years when required.

Example: P=1000, R=10%, T=2 years → SI=200.

7. Compound Interest

Amount = P(1 + R/100)^T
CI = Amount − P

For annual compounding, interest is added to the principal each period. For multiple compounding periods, adjust the rate and number of periods as specified.

Do not apply simple-interest calculation repeatedly when the question asks for compound interest.

8. Work and Time

If A finishes in x days, A's 1-day work = 1/x

For people working together, add their daily work rates.

A = 1/10 per day, B = 1/15 per day
Together = 1/10 + 1/15 = 1/6
Time = 6 days
LCM-based total work can make fractional calculations easier.

9. Mixture and Alligation

For two components with known prices/concentrations, compare how far each is from the mean value.

Ratio of quantities = Difference from mean / Difference from mean
Make sure all prices, concentrations and units use the same basis before applying a ratio.

10. Ages

  • Age difference between two people remains constant.
  • If present ages are x and y, after n years they are x+n and y+n.
  • For past ages, subtract the same number of years.
Use the age difference as an invariant whenever possible.

11. HCF, LCM and Divisibility

  • HCF is the greatest common factor.
  • LCM is the smallest common multiple.
  • For two positive integers: Product = HCF × LCM.

12. Algebra Basics

(a+b)² = a² + 2ab + b²
(a−b)² = a² − 2ab + b²
a²−b² = (a−b)(a+b)

Factorise before expanding when it saves time. Keep signs consistent.

13. Permutation and Combination Basics

nPr = n!/(n−r)!
nCr = n!/[r!(n−r)!]

Permutation is about arrangement/order; combination is about selection where order does not matter.

Ask first: “Does changing the order create a different outcome?”

14. Probability Basics

Probability = Favourable outcomes / Total equally likely outcomes

Probability lies between 0 and 1. Use complement when the opposite event is easier.

P(not A) = 1 − P(A)

1. Subject–Verb Agreement

Find the real subject first. Ignore intervening phrases that do not change the subject.

RuleExample
Singular subjectThe engineer works.
Plural subjectThe engineers work.
Each/EveryEvery student is ready.
Either/NeitherNeither answer is correct.
Along withThe manager, along with the engineers, is present.
Do not let a nearby plural noun force a plural verb when the main subject is singular.

2. Tenses

Time words such as yesterday, already, since, for, tomorrow and by the time often reveal the required tense.

3. Articles: A, An, The

  • A before a consonant sound: a university.
  • An before a vowel sound: an hour, an honest person.
  • The for a specific, identified or unique noun.
The choice depends on pronunciation, not simply the first written letter.
a university → /yu/ sound
an hour → silent h, vowel sound

5. Pronouns

Subject: I, he, she, we, they
Object: me, him, her, us, them
Possessive: my/mine, his, her/hers, our/ours, their/theirs
Correct: She gave the document to me.
Correct: I completed the document.
Check whether the pronoun performs the action or receives it.

6. Parallelism

Items connected by and/or, or appearing in a list, should normally follow the same grammatical form.

Correct: He likes reading, swimming and playing cricket.
Incorrect: He likes reading, swimming and to play cricket.
When correcting, compare the structures on both sides of the connector.

7. Modifiers

A modifier should be placed close to the word it describes.

Unclear: Walking to college, the rain started.
Better: Walking to college, I was caught in the rain.
A dangling modifier can make the sentence logically incorrect even if individual words are grammatical.

8. Active and Passive Voice

Active: The team completed the project.
Passive: The project was completed by the team.

When converting, preserve the tense and meaning. The object of the active sentence becomes the subject of the passive sentence.

9. Direct and Indirect Speech

Watch pronouns, tense changes and time expressions when converting direct speech to reported speech.

Direct: He said, “I am busy.”
Reported: He said that he was busy.
Do not change every tense mechanically; the reporting context matters.

10. Sentence Correction: Full Checklist

  1. Find the subject.
  2. Check subject–verb agreement.
  3. Check tense consistency.
  4. Check pronouns.
  5. Check articles.
  6. Check prepositions.
  7. Check modifiers.
  8. Check parallelism.
  9. Check word order.
  10. Finally check meaning and idiomatic usage.
Do not select an answer merely because it sounds formal. Grammar and meaning come first.

11. Synonyms and Antonyms

Determine the meaning from context before matching the option.

  1. Read the whole sentence.
  2. Replace the word mentally with each option.
  3. Choose the option that preserves meaning.
  4. For antonyms, look for the true opposite rather than a loosely related word.

12. Vocabulary in Context

Unknown words can often be decoded using nearby clues.

  • Contrast: however, although, unlike.
  • Cause: because, since, due to.
  • Result: therefore, hence, consequently.
  • Example: for example, such as.
  • Definition: that is, meaning, refers to.
Read one sentence before and after the unfamiliar word.

13. Para Jumbles

  1. Find the opening sentence; it usually introduces the topic without relying on an earlier reference.
  2. Find mandatory pairs.
  3. Track pronouns and demonstratives such as this, these, such, they.
  4. Track connectors such as however, therefore, finally.
  5. Use chronological or cause-effect order.
A sentence beginning with “This” or “These” often needs a previously introduced noun or idea.

14. Reading Comprehension

Question types

  • Main idea
  • Specific detail
  • Inference
  • Vocabulary in context
  • Author's purpose/tone
  • True/False/Not stated

Method

  1. Read the question and identify its target.
  2. Locate the relevant paragraph.
  3. Use evidence from the passage.
  4. Eliminate options that contradict or overstate the text.
Be especially careful with NOT, EXCEPT, FALSE and LEAST questions.

15. Tone and Inference

For tone, distinguish between what the passage says and how the author presents it.

  • Positive/supportive
  • Negative/critical
  • Neutral/informative
  • Cautious/qualified
Do not infer an extreme opinion when the passage only makes a limited or cautious claim.

1. Variable Tracing

Write the initial value of every important variable. After each assignment, update the value on paper.

x = 5
x = x + 2 → x = 7
x = x × 3 → x = 21
Do not calculate several assignments mentally when the code contains branches or loops.

2. For Loops

Separate the loop into initialization, condition and update.

for(i=1; i<=5; i++)
Values: 1, 2, 3, 4, 5
Check < versus <=. This is one of the most common off-by-one errors.

3. While Loops

Check the condition before each iteration. Confirm that the loop variable eventually changes so the condition can become false.

Write a small iteration table: iteration | variable | condition | output.

4. Nested Loops

Count the inner loop for each outer iteration. Do not automatically multiply the limits if the inner range depends on the outer variable.

Outer 5 times × inner 4 times = 20 only when the inner loop really runs 4 times every time.

5. If / Else Conditions

  • Evaluate the condition exactly as written.
  • AND requires both true.
  • OR requires at least one true.
  • NOT reverses the Boolean value.
  • Nested conditions must be evaluated from the outer branch inward.

6. Increment and Decrement

Pay attention to whether the value is used before or after the increment/decrement when the language-style pseudocode distinguishes them.

Post-increment: use current value, then increase.
Pre-increment: increase first, then use.

7. Integer Division and Remainders

When pseudocode uses integer variables, determine whether division keeps a fractional value or truncates it according to the question's stated convention.

12 ÷ 5 → quotient 2, remainder 2
Do not assume decimal output when the pseudocode clearly uses integer arithmetic.

8. Arrays

  • Check whether indexing starts at 0 or 1.
  • Distinguish index from stored value.
  • For a loop, write the visited indices explicitly.
  • Check array boundaries.

9. Pseudocode Solving Workflow

  1. Read once for overall structure.
  2. List variables and initial values.
  3. Mark loops and conditions.
  4. Trace one iteration carefully.
  5. Repeat until termination.
  6. Read the final output statement.

1. Ordering and Scheduling

  1. Draw positions.
  2. Place fixed positions first.
  3. Apply before/after constraints.
  4. Apply immediate-before/after constraints.
  5. Fill remaining positions by elimination.
“R is immediately after S” → treat S-R as a block until another condition separates them.

2. Linear Seating

Number seats from left to right. Translate every statement into a positional constraint.

  • Immediate left/right = adjacent.
  • Left/right somewhere = any position on that side.
  • Between = check whether the wording means positional or relational placement.

3. Circular Seating

For circular arrangements, fix one person at a reference position to remove rotational duplication. Then apply clockwise/anticlockwise conditions carefully.

Do not use the linear left/right interpretation without considering the circle's orientation.

4. Constraint Tables

Use a table for people × attributes, days × tasks or positions × candidates.

Confirmed = ✓
Impossible = X
Unknown = blank
Apply the strongest constraints first: fixed positions, exact pairs and immediate relationships.

5. Possibility vs Necessity

Can be true: find one valid arrangement. Must be true: the statement must hold in every valid arrangement. Cannot be true: every attempt violates a condition.

One valid example is enough for “can”, but one example cannot prove “must”.

6. Ranking and Comparison

Convert comparisons into a chain.

A > B, B > C → A > B > C

Check whether the requested position can be derived directly or requires combining several statements.

7. Data Arrangement

When several attributes are mixed, separate them into columns. Never try to hold the entire grid mentally.

Cross out impossible pairings as soon as a condition rules them out.

8. Critical Thinking Workflow

  1. Write every condition in short form.
  2. Identify the strongest constraint.
  3. Build the smallest possible table/diagram.
  4. Use elimination.
  5. Test the requested option.
  6. Check that no condition was forgotten.

1. 90-Minute Mock Strategy

54 questions / 90 minutes ≈ 1.67 minutes per question on average

This is an average, not a mandatory time limit for every question. Direct questions should take less time; complex puzzles can take more.

2. Three-Pass Method

  1. Pass 1: Solve questions you can answer confidently and quickly.
  2. Pass 2: Solve medium questions requiring calculation or careful reasoning.
  3. Pass 3: Return to long puzzles, difficult pseudocode and uncertain questions.

4. When to Skip

Skip temporarily when you are rereading the same question, repeatedly restarting a calculation, or unable to identify a valid approach.

Skipping is a time-management tool, not giving up. Return after collecting easier marks.

5. Accuracy Rules

  • Read the question completely.
  • Underline mentally important words: NOT, EXCEPT, ONLY, MUST, CAN.
  • Check units.
  • Estimate the answer before long calculations when possible.
  • Use elimination.
  • Do not change an answer without a concrete reason.
